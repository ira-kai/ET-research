# Learning File: Fixing CPS Boundary Degradation

How to retrofit boundary awareness into SegUNET's existing CPS
semi-supervised training pipeline.

---

## Why CPS Hurts Boundaries

Cross Pseudo Supervision (Chen et al., CVPR 2021) trains two networks
with identical architecture but different random init. Each generates
pseudo-labels for the other on unlabeled data.

The failure mechanism is specific and well-understood:

1. **One-hot pseudo-labels** — CPS converts soft predictions to hard
   one-hot labels before cross-supervision. At boundary pixels where the
   model is uncertain (say 55% Sclera, 45% UpperLid), the pseudo-label
   becomes 100% Sclera. The supervising network receives full wrong signal.

2. **Catastrophic stability** — when both networks make the same boundary
   error (which happens when the labeled set lacks that boundary config),
   the consistency loss is zero. There's no corrective signal. The error
   is *stable* under CPS.

3. **Boundary pixels are rare** — CPS's loss is computed uniformly. If
   boundary pixels are 3% of the image, they contribute 3% of the gradient.
   Interior pixels dominate learning.

This explains why SegUNET's boundary mIoU (0.7207) lags region mIoU
(0.9026) — CPS is actively reinforcing boundary errors.

---

## Fix 1: BoundMatch (IEEE Access 2025) — HIGHEST PRIORITY

**What it does:** Adds a second consistency target — in addition to
requiring teacher and student to agree on *segmentation masks*, it
requires them to agree on *semantic boundary maps*.

The boundary maps are not binary edges. They are **multi-class**: each
boundary pixel is labeled with the *pair of classes* it separates.
So UpperLid/Sclera boundary ≠ UpperLid/Iris boundary.

**Two key modules:**
- **BSF (Boundary-Semantic Fusion):** Injects learned boundary cues back
  into the segmentation decoder
- **SGF (Spatial Gradient Fusion):** Computes boundary predictions from
  mask spatial gradients, producing higher-quality boundary pseudo-labels

**Why it's the top pick:**
- Designed as a plug-in to teacher-student frameworks (CPS is one)
- Multi-class boundaries directly address medial canthus
- Publicly available code
- No architecture change needed — same encoder, same decoder

**Implementation notes:**
- Compute GT boundary maps from label masks during data loading
  (Sobel or morphological gradient on each class mask)
- Add boundary head to each CPS network (small conv block)
- Add boundary consistency loss alongside segmentation consistency loss

## Fix 2: CW-BASS (IJCNN 2025) — Simplest Single Change

**What it does:** Three modifications to standard CPS:

1. **Sobel boundary detection** on pseudo-labels → boundary supervision
   signal (differentiable, unlike Canny)
2. **Confidence weighting** — each pseudo-label pixel weighted by model
   confidence. Low-confidence boundary pixels get downweighted rather
   than excluded
3. **Dynamic threshold** — the confidence cutoff adapts per-epoch based
   on model performance

**Key result:** The boundary-aware Sobel loss alone contributed **+6.36%
mIoU** in ablation — the single largest contributor in the framework.

**Why choose this over BoundMatch:** Simpler to implement. BoundMatch
requires multi-class boundary maps and two fusion modules. CW-BASS just
adds Sobel filtering + confidence weighting to existing pseudo-labels.

**Code:** `repos/CW-BASS/main.py`, `repos/CW-BASS/model/semseg/deeplabv3plus.py`

## Fix 3: MPDC (Pattern Recognition 2025) — Break the Echo Chamber

**What it does:** Adds a third network perspective to CPS. The two
original networks plus a fused third view cross-supervise each other.
The fusion perspective is semantically "rotated" — it sees the data
differently, breaking the mutual reinforcement of boundary errors.

**Key insight:** Two networks with same architecture and same data
develop "model cognitive bias" — they learn similar errors. The third
perspective, generated by fusing features from both, provides a
genuinely different view.

**Result:** 0.47 improvement in 95th-percentile Hausdorff Distance
(a direct boundary quality metric) on ACDC with 10% labels.

**Trade-off:** One extra forward pass during training. Zero inference cost
(only one network deployed).

**Code:** `repos/MPDC-net/code/networks/net_factory.py`

---

## Fix 4: n-CPS (arXiv 2021) — Brute Force Variance Reduction

Train n=3 or n=4 networks instead of 2, ensemble at inference.
More networks → boundary prediction variance decreases.

**Trade-off:** Proportionally more GPU memory. Only worth it if
Fixes 1-3 are insufficient.

## Recommended Progression

```
Week 1: Add CW-BASS Sobel boundary loss to existing CPS
         (simplest change, +6% mIoU expected)
         ↓
Week 2: If boundary mIoU improves but medial canthus still fails,
         add BoundMatch multi-class boundary consistency
         ↓
Week 3: If both networks still agree on wrong boundaries,
         try MPDC 3-branch to break cognitive bias
         ↓
Ongoing: Use SBC-AL to query highest-value boundary annotation
         candidates from unlabeled pool
```

## Active Learning: SBC-AL (MICCAI 2024)

None of the training fixes address the root cause: the labeled set
lacks boundary diversity. SBC-AL provides the querying strategy to fix this.

**How it works:**
1. Run augmented views through both CPS networks
2. Compute Structure Consistency Score (SCS) — interior agreement
3. Compute Boundary Consistency Score (BCS) — boundary agreement
4. Select frames where SCS is high but BCS is low

These are frames where the model understands the anatomy (which classes
are present) but is confused about exactly where they meet — precisely
the UpperLid/medial canthus frames missing from labeled coverage.

**Paper:** `papers/sbc-al-miccai-2024.pdf`

## Post-Processing Stack (Inference Time)

After training fixes, add inference-time boundary refinement:

```
Model output (7-class logits)
    │
    ├─ Canny edge prior × decoder features (OASIS, <0.5ms)
    │   Sharpens all boundaries with zero learned params
    │
    ├─ SegFix direction map on NON-junction boundaries (~2-4ms)
    │   Replaces boundary pixels with interior labels
    │   EXCLUDE medial canthus (ambiguous interior direction)
    │
    └─ Dense CRF on interior regions (~3-5ms)
        Smooths noisy predictions within homogeneous areas

Total post-processing: ~6-10ms (fits 11ms budget with model)
```

**Code:** `repos/SegFix/`, `repos/OASIS/`, `repos/pydensecrf/`
